SRTGUIDE — CHARACTER & STORY

キャラ紹介・相関図

『3on3 FreeStyle』全61キャラの紹介と関係性だけをまとめたページです。アイコンは公式キャラアートから切り取った顔になっています。カードをクリックすると、そのキャラの物語・プレイの特徴・関係するキャラが開きます。関係は根拠の強さで3段階に分けて表示しているので、「公式設定」と「共通点からの読み」を混同せずに楽しめます。スキルの効果を調べたいときは、上のタブから別ページの「スキル一覧」へどうぞ。

公式に明記紹介文・公式発表に直接書かれている関係 動画で確認公式ティーザー／スポットライト動画の物語から分かる関係 共通点からの推測出身・所属・境遇の共通点でつないだ、断定しない読み
つかい方：上の検索・ポジション絞り込みで探す → カードをタップ → 詳細の「関係するキャラ」から相手のページへそのまま移動できます。「相関マップ」表示では、物語の核になるグループごとに線の意味も読めます。スキルはこのページには混ぜていません（別ページ）。

条件に合うキャラが見つかりませんでした。検索語やポジションを変えてみてください。

SRTGUIDE — SKILL LIST

スキル一覧

キャラ相関とは別ページの、スキルだけの一覧です。公開資料で確認できたスキルについて、効果と所持キャラをまとめています。複数キャラが持つスキルは共通スキルとして1件にまとめ、1キャラ（または特定ペア）だけのスキルは固有スキルとして分けています。強さの評価は付けていません。

つかい方：スキル名・効果の言葉（例：ダンク、パス、スティール）で検索し、共通／固有で絞り込めます。各スキルの「所持キャラ」をタップすると、キャラ相関のページへ移動してそのキャラの詳細が開きます。

収録範囲について：これは公開資料で確認できたスキルの一覧です。同名でも効果が別物のスキル（例：Tenacity、Spin Move）は混同しないよう分けて載せています。効果の公式説明が公開資料で確認できなかったスキルは、その旨を明記しています。

固有スキルが公開資料で確認できなかったキャラは Carter / Christa / Fei / Carolina / Jimmy / Jason / Max / Luther / Clarke / Murdock / Lulu / Amanda / William / Pedro / Walker / Rebecca / Little Fox / Giant G / Kaji / Gena / Howl / Camila / Professor / Rin の24人です（Siana は1件のみ確認）。この24人のうち14人は共通スキルの所持者として登場しますが、Little Fox / Christa / Fei / Carolina / Jimmy / Pedro / Professor / Gena / Howl / Camila の10人は共通スキル側でも所持が確認できていません。

条件に合うスキルが見つかりませんでした。検索語を変えてみてください。
